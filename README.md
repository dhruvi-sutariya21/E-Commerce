# Women’s E-Commerce Backend API

A Women’s E-Commerce Backend API developed using **FastAPI**.

## Features

* User Registration
* User Login
* JWT Authentication
* Product Management (CRUD)
* Category Management (CRUD)
* Cart Management
* Wishlist Management
* Order Management
* Payment Management
* User Profile
* Role Based Authentication
* Secure Password Hashing

## Technologies Used

* Python
* FastAPI
* SQLAlchemy
* Pydantic
* JWT Authentication
* Bcrypt
* Alembic
* SQLite
* Uvicorn

## Installation

```bash
git clone https://github.com/dhruvi-sutariya21/E-Commerce.git
cd E-Commerce
pip install -r requirements.txt
uvicorn main:app --reload
```
